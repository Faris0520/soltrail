# SolTrail

Learn Solana by doing the Devnet missions in order.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Use Phantom on Solana Devnet.

Optional RPC override:

```bash
NEXT_PUBLIC_SOLANA_RPC_URL=https://api.devnet.solana.com
```

## Check

```bash
npm test
npm run lint
```
